
# 📝 JavaScript Course - Functions Assignments

These assignments cover JavaScript functions, including definitions, parameters, return values, and combining functions with logic and loops.

---

# 📝 Assignment 1 – Basic Greeting Function

## 🎯 Goal:

Practice defining and calling simple functions with parameters.

## 📌 Task:

1. Create a function named `sayWelcome` that takes a `username` as a parameter.
2. Inside the function, print `"Welcome, [username]!"` to the console.
3. Call the function three times with different names (e.g., "Kareem", "Ahmed", "Sara").

---

# 📝 Assignment 2 – Calculating Multiples

## 🎯 Goal:

Practice using function parameters for mathematical calculations.

## 📌 Task:

1. Create a function `multiplyThreeNumbers` that takes three parameters: `n1`, `n2`, and `n3`.
2. The function should log the result of multiplying all three numbers together.
3. Call the function with any three numbers and check the console.

---

# 📝 Assignment 3 – Using Return Values (Area Calculation)

## 🎯 Goal:

Understand how to use `return` to pass data back from a function.

## 📌 Task:

1. Create a function `calculateRectangleArea` that takes `width` and `height`.
2. Instead of logging, the function should **return** the result of `width * height`.
3. Call the function and store the result in a variable named `area`.
4. Log the value of `area` to the console.

---

# 📝 Assignment 4 – Conditional Logic in Functions (Pass/Fail)

## 🎯 Goal:

Combine functions with `if/else` statements.

## 📌 Task:

1. Create a function `checkExamResult` that takes a `score` parameter.
2. If the score is **50 or more**, return the string `"Passed"`.
3. Otherwise, return the string `"Failed"`.
4. Test the function by logging the result for scores `45` and `80`.

---

# 📝 Assignment 5 – Filtering Arrays with Functions

## 🎯 Goal:

Practice using functions to process arrays and return new data.

## 📌 Task:

1. Create a function `filterSmallNumbers` that takes an array of numbers.
2. The function should loop through the array and find numbers **less than 100**.
3. Push these small numbers into a new array and **return** it.
4. Test it with the array: `[10, 150, 30, 200, 5, 500]` and log the final result.

---

# 📝 Assignment 6 – Anonymous Functions (Square a Number)

## 🎯 Goal:

Practice declaring and using anonymous functions.

## 📌 Task:

1. Declare a variable `square` and assign it an anonymous function.
2. The function should take one number `n` and return `n * n`.
3. Call the function using the variable name `square(5)` and log the result to the console.
